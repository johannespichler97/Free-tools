How the Score Is Calculated

Exponential Moving Average (EMA)

For a period n, the smoothing factor α and recursive formula are:
α = 2 / (n + 1) EMAn(t) = α · Pt + (1 − α) · EMAn(t−1) Seed (t = n): EMAn(n) = (1/n) · Σ Pi for i = 1…n
Three EMAs are computed per instrument: EMA20, EMA50, EMA200.
280 historical candles are fetched per request to ensure EMA200 is fully warm with 80 bars of runway before the current bar.

EMA₂₀ Slope (5-bar momentum)

Rather than comparing the EMA to a fixed baseline, the slope measures the direction of the EMA itself over the last 5 completed bars:
Slope₅ = EMA₂₀(t) − EMA₂₀(t−5) S₄ = +1 if Slope₅ > 0 S₄ = −1 if Slope₅ ≤ 0
A positive slope means the short-term average is accelerating upward — a precursor to trend continuation. A negative slope flags potential exhaustion even when price is still above the EMA.

Four Binary Signals

S₁ = +1 if Pt > EMA₂₀(t), else −1 S₂ = +1 if EMA₂₀(t) > EMA₅₀(t), else −1 S₃ = +1 if EMA₅₀(t) > EMA₂₀₀(t), else −1 S₄ = +1 if EMA₂₀(t) > EMA₂₀(t−5), else −1 Score = S₁ + S₂ + S₃ + S₄ ∈ {−4, −2, 0, +2, +4}
Each signal is independently binary (±1), so the composite score is always even. All four signals aligned in the same direction yields the maximum magnitude (±4).
